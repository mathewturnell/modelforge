# Provenance

The four selected `tastematch` Python files are ModelForge integration code
licensed under Apache-2.0 following the 2026-09-10 rights-holder confirmation.
No upstream source is copied here.

Food-101's notice identifies third-party Foodspotting imagery and does not
establish general redistribution rights, so no images are included. The exact
SigLIP revision `9fdffc58afc957d1a03a25b10dba0329ab15c2a3` declares
Apache-2.0 in its official model repository; its weights remain external for
size and provenance. No trained adapter is included.
