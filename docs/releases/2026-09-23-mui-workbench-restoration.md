# Restore the established ModelForge workbench on React and MUI

The preceding client preserved execution paths while replacing the original
interface. This change restores the familiar workspace composition and
interactions using React with MUI as the shared component and theme foundation.
The new backend architecture remains in place.

## What changes

- The title cockpit, icon rail, document strip, contextual collections and status
  area return to the established compact graphite layout and product marks.
- Output and Logs return to a collapsible bottom panel with readable timestamped
  lines. The current run retains its authoritative state, recovery and artifacts.
- The original React Flow model presentation returns: colored contract nodes,
  dependency edges, pan/zoom, minimap, keyboard selection, inspector and model
  brief. Checked descriptors can carry bounded display metadata.
- Training uses Recharts with the original comparison cards, hover values,
  legends, metric summaries and single-run essential curves. Missing telemetry
  remains missing; irregular coordinates and exact numbers are preserved.
- Annotation opens full-screen with tool rail, colored tracks, object properties,
  actual frame timeline, pan/zoom, box draw/move/resize, undo/redo and JSON export.
  Source-bound revision checks, protected splits and unchanged media remain intact.
  Bounded temporal sidecars now support 10,000 rectangles within 4 MiB.
- Jobs returns to a full-width registry with state counts, filters, workload,
  compute and output evidence. Opening a job restores its owning project/run.

MUI is the actual component foundation, including theme, buttons, tabs, dialogs,
selection controls and tables. Specialist React Flow/Recharts renderers are
bundled locally. Emotion styles use document-specific CSP nonces; no broad
inline-style or script exception is introduced.

## Evidence and remaining limits

Local validation: **342 Python tests**, **26 frontend tests**, and **27 browser
journeys passed**, with two explicitly optional capture skips. The browser
suite includes the published 1728 × 1080 geometry and 390 px interaction checks.

The real selected annotation sequence contains **3,594 source rectangles across
203 frames and 79 tracks**, with revision-preserving import into a separate
checked project. Model review uses the original six-node declared architecture,
configuration values and the same selected memory-query node.

Verification includes source-backed comparison against the published reference
screenshots, original desktop geometry, real UI interactions, narrow viewport
checks, accessibility, persisted run/annotation evidence, strict CSP, package
inventories and deterministic service/chart tests. Functional success and visual
fidelity are recorded separately.

The current model/training data is not replaced with old screenshot numbers.
Absent source-membership declarations, full assistant execution, polygon/review
annotation workflows, historical scientific metrics and the interactive Weather
3D viewer remain explicit gaps. Restoring the screen does not prove full legacy
feature or scientific parity. Real Modal verification remains subject to the
previously recorded exact-upload block; this UI change launches no paid compute.
